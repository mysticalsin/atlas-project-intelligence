# Assessment: gate head

## Symptom
A gate number was reported for a commit, then another commit landed. The body named the earlier commit as the head.

## Expected
Every gate number is from the commit that was pushed, and the body names that commit.

## Actual
The fifth-round body named a product commit, and the following commit was docs only.

## Verdict
valid

## Severity
Medium. Process (P-1).
