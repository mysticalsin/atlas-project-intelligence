## Decisions and deviations (for the integration review)
- **Answer windows, refined.** §F2.4 counts an attempt at the item's `audio_turn` and records `askByItem` "when a reply is composed". In practice the greeting or acknowledgement prefix reaches `audio_turn` *before* the talker's text is composed, so the ask would be unknown or stale there.
  - The ask is fixed when `talkerMessages` is built for the reply.
  - The attempt is counted, and `openAsk` switched, at the first chunk of that reply's audio in `pace()` (the same place, one chunk later).
  - A reply withdrawn because the consultant carried on gives its attempt back.
  - The closing (`TIME_UP`), the "still thinking" nudge and the noise re-ask (`RESUME`) carry no ask: they never switch the window or count an attempt.
- **Plan moves on at once.** `finishTurn` in gap mode records the turn, then recomputes `gapGuidance` synchronously before the reply is composed. The analyst-job recompute (§F2.4) also runs. Without the synchronous step the reply to an answer carried the *previous* ask, and the next answer was filed under it. A test holds the analyst back to prove this.
- **Merged continuations** extend the same window entry as a separate part. Status uses the joined text; quotes stay exact transcript substrings (§F2.4 "exact substring").
- **Resolver output bounded in Session**: at most 3 asks, known fields only, labels from `FIELDS`, asks cut to 160 characters, ids deduped after validation.
- **WIN_HINTS lookup** uses `Object.hasOwn`, so a `__proto__` or `constructor` hint adds nothing.
- **gaps.js** (the spec is silent on these):
  - `source` records how the assignee was chosen (`typed` | `reference` | `reference_public`). `assigneeEmail` goes to admins, the assignee, and the creator unless `reference_public`; `draft.to` is then empty.
  - A dismiss `note` is bounded but not stored: there is no column, and there is no ALTER.
  - `projectId` is stored only when the assignee has full access to the reference.
  - Answers are pseudonymised with the request map, and the bid's declared prospects are masked too.
  - An answer is accepted only while the request is open (409 afterwards; 404 for non-assignees). An unknown ask or status gives 400. Quotes are bounded silently (≤5, ≤400 code points).
  - An answer's `referenceId` is kept only when the assignee has full access to it.
  - The 30-day expiry also applies at read time, not only in the daily sweep.
  - The POST response adds `draft.link` and `outreach: [{id, channel, status, reason}]`. An outreach queue failure never fails the request.
  - An unknown requirement kind gives 400.
- **voice-client**: only the request this start used is consumed, and only while the workspace still offers it, so a newer pending request is never cleared. The gap-mode message says nothing was sent; the existing "Save on this device" prompt is still offered when the workspace is not persisted.
- **CLAUDE.md vs spec**: no conflict found. In admin + gap mode, `ADMIN_NOTE` ("never end on your own") precedes `GAP_NOTE` ("go to ENDING"), in the spec's order.
