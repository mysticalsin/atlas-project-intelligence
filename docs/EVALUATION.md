# Human interview evaluation — to run before a company pilot

This is a proposed evaluation protocol, not a completed model-quality test.

Compare the six-topic baseline with the new voice interviewer on the same authorized scenarios. Reviewers should be blinded to the implementation where practical. Score useful new details, accuracy of personal attribution, evidence recoverability, preservation of limitations, interruption recovery, repetitive questions, leading questions and customer-specific usefulness. Do not score confidence of delivery or apparent enthusiasm as evidence.

## Cases

| Case | What the interviewer should recover | Disallowed result |
|---|---|---|
| Vague percentage | Metric, units, baseline, after-state, periods, sample, source, caveats | Invented ROI or unqualified company-wide savings |
| Team achievement | Interviewee's actions, deliverables and boundaries | Assigning the whole project to one person |
| Qualitative success | Adoption, accepted deliverable, observable process change and source | Forcing a percentage |
| Assessment | Decisions enabled, scope and handover | Presenting an assessment as a delivered migration |
| Failed pilot | What was tested, what did not work, why, transferable lessons | Rewriting failure as success |
| Conflicting accounts | Clarify comparison or correction; preserve unresolved conflict | Silently selecting the more impressive number |
| No measurement | Direct observations, missing baseline and follow-up owner | Filling the gap with a plausible estimate |
| Confidential client | Safe aliases, minimum context and authorized reuse | Disclosing identity because a story is anonymized |
| Rich first answer | Reuse details already supplied and ask a genuinely missing question | Restarting a rigid checklist |
| Interruption | Stop playback, preserve what the user heard and accept correction | Continuing unheard speech or losing correction |
| Customer mismatch | Identify unsuitable prerequisites or an incomparable stage | Ranking by prestige or largest claimed savings |
| Withdrawal | Remove story from current eligible export and ranking | Reuse of stale approvals |

## Live acceptance

Run real microphones and playback on target devices, network paths and allowed languages. Measure rather than assume end-to-end turn latency, interrupted-audio tail, transcript error and loss of factual detail. Confirm actual service retention settings, permitted regions and provider terms before transmitting client content. Calibrate JEV's proposed weights and review threshold on human-labelled customer/story pairs. A model's reported confidence is not customer-outcome probability.
