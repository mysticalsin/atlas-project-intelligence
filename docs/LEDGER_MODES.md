# Production spend meter: `LEDGER_MODE`

**Status (cap v2):** production `wrangler.jsonc` sets `LEDGER_MODE=enforce` and binds `ProductionSpendLedger` as `SPEND_LEDGER` (migration `v3`, `new_sqlite_classes`). The class the Worker exports extends `DurableObject` from `cloudflare:workers`. The pure ledger in `meter.js` does not, so the Node tests can construct it. `wrangler.jsonc` binds it as `SPEND_LEDGER` and declares it in migration `v3` as `new_sqlite_classes`, the same form as `Interview` and `LibraryStore`. No `PRODUCTION_MONTHLY_LIMIT_USD` override, so the $5 UTC-month default applies. The workerd test uses that default: it reserves, settles and snapshots through the binding, refuses a retain priced at $6, and records an overrun when settle prices above the reservation. Settle is not clamped. Unset `LEDGER_MODE` means **enforce**. Explicit `off` is only a local mocked run: loopback, `ATLAS_AUTH=local`, and no paid upstream. `dev/local-edge.mjs` is that mocked edge. `scripts/run_local_voice.sh` and `scripts/pod_setup.sh` do not set off. This branch does not carry the live-test ledger or early processing. It has not been exercised against a live provider. A live Cloudflare Access check was not run.

## The three modes

`LEDGER_MODE` is a Worker variable, and the same name on the Python process. Production sets `enforce`. The paid local voice scripts do not set off.

- **unset, empty, or omitted** means enforce. A missing ledger refuses the call.
- **off** is explicit and only for a mocked provider. The call is made exactly as before: the same arguments, same count and order, and the same result object. No estimate is computed, and `SPEND_LEDGER` is never read. The factory writes one log line, `{atlas_metric:'ledger', mode:'off'}`. The process refuses to start in off when a paid key or a paid host is configured, or when it is not loopback with `ATLAS_AUTH=local`. `test/ledger-off.test.js` compares the off scenario with a golden recorded on this branch.
- **observe** never blocks or delays a call.
  - Each call writes one log line: `atlas_metric: ledger`, the kind, the configured model or provider name, numbers (audio ms, token estimates, characters, files, requests) and an estimated USD figure, or `null` when unpriced. It never contains prompt, transcript, story or key text.
  - When a `SPEND_LEDGER` binding exists, the estimate is also sent to its `record()` without being awaited.
  - When the binding is missing, or a lookup or `record()` throws, rejects or hangs, the result is log-only and the call is unaffected.
- **enforce** is the default, including when the variable is unset. It is not opt-in. Before the upstream call, the ledger must return `{ ok: true, id }` from `reserve()`.
  - Each of these refuses the call with a `BudgetRefused` error and nothing reaches the upstream: no binding (`no_ledger`); a throw or rejection (`ledger_error`); no answer within 1 s (`ledger_timeout`); a malformed answer; or a refusal from the ledger (`exhausted:usd`, `unpriced`, `limit_unset`).
  - After the call, `paid()` awaits settle. Settle charges the usage the response returns and refunds the rest of the reservation. Usage above the ceiling is stored in full and flagged in the same step (`overruns`). It is not clamped. A recorded overrun latches the month: the next reserve is `exhausted:usd`, the real amount stays, and the log is `{atlas_metric:'ledger', event:'overrun', id, month}` with no dollar amount and no model name. The stored phase stays `open` so a reload does not wipe the spend; `snapshot()` reports `phase: 'exhausted'`. Missing usage keeps the ceiling. A failed settle throws `BudgetRefused('ledger_error')` and does not shrink the reservation, so the month keeps the full ceiling. The model result is not given a flag: those results are strings, audio bytes and Response objects. On an upstream error the wrapper still attempts one ceiling settle; if that settle fails, the original error is rethrown with `ledger` set to `settle_failed`. A Workers AI binding settle (`@cf/` or markdown) prices the reported usage and adds `PROXY_PER_CALL_NANO`. A streamed talker settles the usage the SSE body reports, plus that proxy. An `actualNano` the caller already computed is not given a second proxy.
  - Each analyst attempt reserves on its own. A ledger refusal is not retried.
- **Any other value**, for example a typo, refuses every paid call (`invalid_mode`). A typo does not mean off, and it does not mean enforce. The admin readout shows that mode as `invalid`.

The guarantee in each mode is only what is listed here. Off guarantees unchanged behaviour, not any spend limit. Observe guarantees records only when a working ledger is bound; otherwise it guarantees log lines. Only enforce bounds spend, and only to the extent of its known limits listed below.

## Why unset means enforce

Tony's decision, via Jarvis at 18:19 BRT on 2026-11-11: "Everything AI: price every model call and put all of it under the same $5." An unset variable must not leave a paid call unmetered. Production config is enforce and a test fails if it is off. A paid local run does not set off. Observe stays available, records when a ledger is configured, and never blocks.

## Production limit: $5 per UTC month

Tony's decision, relayed via Jarvis at 17:03 BRT on 2026-11-11: production voice spend is **$5 per calendar month** (UTC), fail closed. `PRODUCTION_MONTHLY_LIMIT_USD = 5` in `src/meter.js`. The earlier $15 per UTC day proposal is not the limit.

Admission is `month-to-date reserved nano + this call's worst case <= 5_000_000_000` nano-dollars (`Math.round(5 * 1e9)`). Equal to the cap is admitted. One nano over is `exhausted:usd`. Settle then replaces the ceiling with the actual nano when the response carries usage, refunding the difference, or adds the overrun and increments `overruns` when the actual is higher. A settle with no usage, including an error, keeps the ceiling. The next UTC day in the same month does not reset the counter. At `YYYY-MM-01T00:00:00Z` the pure `rollover` event in `src/month-budget.js` copies open reservations, their ceiling nanos and `next` into the new month. Settled spend and the overrun latch do not carry. A later settle finds the id in the month that now holds it. A month with nothing open opens at zero reserved. That file is the only writer of the month. An open reservation older than 120 seconds is settled at its ceiling and counted in `settled.unsettled`. It is not dropped. `docs/STATE-MACHINE-STANDARD.md` is not vendored on this branch; the machine follows its rules (typed states and events, one pure transition, no I/O in the reducer, versioned persistence, unknown or legacy records deny and are not healed).

The worst case for a Workers AI binding call (`@cf/…` or `toMarkdown`) is the list-price ceiling plus the binding proxy worst case, `0.30 / 1e6 + 300000 * 0.02 / 1e6` dollars (`PROXY_PER_CALL_NANO` = 6,000,300). ElevenLabs, Hindsight and TypeSafe are direct fetches and do not get the proxy. A model or provider with no price still returns null from `priceOf` and is refused under enforce. Every kind production can call now has a positive ceiling, so that refusal is for a future unpriced kind, not for the current set. `test/priced-kinds.test.js` fails if a `paid()` estimate arrow names a kind or provider without one. The $1.50 live-test ledger is not on this branch.

The default applies when the limit is omitted. Production omits it. An explicit null, blank, zero, negative or unparseable `limitUsd` or `PRODUCTION_MONTHLY_LIMIT_USD` denies with `limit_unset`. A ledger read or write failure denies with `ledger_error`. A legacy day record, a bad version or a month that is not `YYYY-MM` denies with `unknown_month` and stays denied across the next month boundary. None of these fall through to an unmetered provider call. Only `exhausted:usd` ends a voice session with `budget_exhausted` and `BUDGET_MESSAGE`. A ledger, unpriced or timeout refusal uses the existing sentence `The voice reply failed. No fallback voice was used.` with code `voice-unavailable` and stops the turn. `checkTurn` fails closed on those refusals. The 350 ms turn-model timer is not a ledger timeout.

## What is still not a true bound

These are named so they are not reserved as if they were capped. Settle still records an overrun. It does not clamp.

- Hindsight retain can still bill tokens the service generates beyond the request body. list, delete, stats and bank reserve the flat ceiling above. A response whose token charge exceeds that flat ceiling is an overrun. No output cap is published. Worst case above the flat ceiling: not published.
- OpenAI realtime audio is about 10 input and 20 output tokens per second, with special-token variation that has no published maximum. Each 30-second increment includes one in-flight response via `max_output_tokens`. A special-token bump on the response that crosses the increment can still record an overrun. Worst case of that bump: not published.
- gpt-oss: the model page does not say whether `max_tokens` includes reasoning. ATLAS sends and reserves `maxTokens + reasoningTokens`. When reasoning is reported above completion, both are charged. If a response reports a sum above the sent cap, that is an overrun. The 128,000 context window is not a per-call bill.
- A PDF whose page objects sit in a compressed stream is not counted. A Word, HTML or other non-PDF file has no page count ATLAS can read. Both are refused above 10 MB and, when allowed, reserved at the 30-page cap. A compressed or non-PDF file under that byte cap can cause more image work than 30 pages. Worst case of that extra work: not published.
- A provider chat template can add tokens that are not in the UTF-8 body. No per-call maximum for that template is published. The input ceiling is one token per byte of the body that is sent. Worst case of the template: not published.
- Kyutai speech recognition and synthesis are continuous self-hosted sockets. They are not reserved on the month ledger, and there is no per-call audio-second cap on those sockets. Worst case against the $5 ledger: they add nothing to it. Worst case audio duration: the interview. No dollar price for that duration is published here.
- PersonaPlex is a local conversational socket. It is not reserved. Worst case against the $5 ledger: it adds nothing to it.
- Optional NVIDIA Riva transcription (`atlas_voice/notes.py`) sends the microphone recording in 25-second chunks, stops after 150 seconds, and stops the text at 60,000 characters. The URI does not say whether that deployment is billed, and no list price is in this table. Under enforce the call is refused with reason `unpriced` before the client is built. Observe records the audio length and still calls. Worst case dollar amount: not published.

## The visible stop

`exhausted:usd` is the one month-stop outcome. `src/budget-stop.js` is a pure reducer: `pending` plus `refusal` / `exhausted:usd` becomes `{ phase: 'exhausted', code: 'budget_exhausted', message: "This month's AI budget is used up." }`. Any other known refusal becomes `closed` with no user message. Effects stay outside the reducer.

Where a feature would have shown model output, the page shows that one sentence and no helper text. A keyword or lexical result may stay, with the same sentence and without the method line. HTTP routes that have no partial result return 429 `{ error, code }` and do not return 502. Ask and recommend stay HTTP 200 with the lexical cards and `{ budget: { code, message } }`, because a partial result plus the sentence beats a 429 that drops the cards. A voice session refused for the month sends `code` `budget_exhausted` and shows that same sentence, read from `BUDGET_MESSAGE`. The page keys on the code. Ledger, unpriced and timeout refusals use the existing voice-failure sentence and code `voice-unavailable`, and they stop the turn. They are not shown as the month sentence and they are not turned into an empty success.

Admin metrics attach `spend` from `ProductionSpendLedger` beside the telemetry rollup: the ledger mode, month-to-date reserved dollars (ceilings still open, plus settled actuals), and the overrun count when it is not zero. An invalid mode is shown as `invalid`. It is not rewritten to enforce. `queryMetrics` itself stays a pure telemetry rollup. If the ledger read fails, the page says the month-to-date figure was not read. It does not show $0 for a failed read. `snapshot()` reads. It does not write.

## Known limits

- **An unpriced call is refused under enforce with reason `unpriced`.** Image conversion is refused that way, with code `unpriced_model`, because detr-resnet-50 has no list price. Under off, which has no paid upstream, the local stand-in may still describe an image. Enforce and observe do not call detr. The editor's OpenAI model is operator-chosen and has no row in `PRICES`; a configured model that is not in that table is refused with `unpriced`. Riva is refused the same way. list, delete, stats and bank use the flat ceiling rather than a null.
- **The numbers in `LIMITS` are the ceilings.** Each call passes that `max_tokens`, audio cap or character cap, and reserves the same number. Input text is one token per UTF-8 byte of the body. Audio is rounded up to whole seconds and refused above its cap. The kinds in "What is still not a true bound" are the ones this does not cover. An actual above the reserved ceiling is still recorded as an overrun. Settle does not clamp it.
- **One global month budget.** There is no per-user or per-tenant limit, and the window is a UTC calendar month. `ProductionSpendLedger.apply` is the single writer. Its throughput under many simultaneous interviews has not been measured.
- **Latency.** Enforce adds a ledger round trip before every call, at most 1 s before it refuses.
- **How callers report the month stop.** `exhausted:usd` becomes the one sentence. `storyRater` rethrows `BudgetRefused` and does not retry it as a network error. A review, a slide deck, insights, a one-pager, a sheet draft and spoken Ask transcription return 429 with that sentence. Recommend, Ask and bid match may keep a lexical result and carry `budget` so the page shows the sentence without a method line. Indexing a reference embeds in the background and has no AI-output surface; a refusal writes no vector and shows nothing new.
- **Production configuration is set.** `worker.js` exports `ProductionSpendLedger`, and that class extends `DurableObject` from `cloudflare:workers`. The pure class in `meter.js` does not, so Node tests can construct it. `wrangler.jsonc` binds `SPEND_LEDGER`, migrates it as `v3` `new_sqlite_classes`, and sets `LEDGER_MODE` to `enforce` with no limit override. A test fails if that file sets off.
- **This branch has no live-test ledger.** The paid local scripts do not set off. `dev/local-edge.mjs` is the mocked edge and still sets off. They do not share a second cap with `paid()`.
- **The static check is a source scan.** It catches direct use, the bracket form `env['AI']` and destructuring from `env`. It does not catch deliberately obfuscated access.
- **The Python application uses the same ledger.** `realtime.py` reserves in 30-second increments, settles leftover usage before a refusal, and keeps the original refusal reason. `editor.py`, `jev.py`, `speech.py` (Workers AI transcribe and synthesize), `analyst.py`, `report.py`, `kyutai.py` `stream_chat`, and `memory.py` (recall, retain, continuity replace, document read and delete) reserve before the upstream request. `stream_chat` re-raises a failed settle after `{atlas_metric:'ledger', error:'settle'}`. A failure during cancellation is logged with `recorded: 'cancel'` and `CancelledError` still propagates. `notes.py` refuses Riva under enforce. An observe record failure, including that Riva path, is logged and does not block. Local Kyutai STT/TTS sockets are self-hosted and are not in that list. `scripts/run_local_voice.sh` and `scripts/pod_setup.sh` do not set off. `start_gateway.sh` refuses off unless the bind is loopback and `ATLAS_AUTH=local`. `create_app` calls `spend.require_ledger` unless `ledger_check=False`.
- This is a cost control, not a security or compliance control, and it makes no claim to be complete.
