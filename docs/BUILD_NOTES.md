# ATLAS Project Intelligence v12

One browser interface and one application gateway. Use a real selected conversational voice provider, a quote-grounded candidate ledger, a bounded next-question planner, private Hindsight continuity and a reviewed Markdown story vault.

Hosted Realtime supports live transcript-linked tools. PersonaPlex retains the GPU and optional Riva post-session route. Neither can publish or approve. The orb responds to played audio, not received text. Silent previews do not connect a microphone or model.

The quality workbench accepts unknowns and confidentiality, separates individual contribution from team outcomes, and frames assessment/qualitative work correctly. Saving creates immutable Markdown candidates. An optional editor proposes a source-linked rewrite; applying and saving remain explicit. Exact-version review belongs to independently authorized humans. The native graph is an eligible-view projection; optional Graphify consumes an authorized snapshot only.

JEV classifies customer-specific relevance from a four-part brief and eligible customer-anonymized records. Code computes the dated-source proxy. A weak match can return no recommendation. These weights are pilot assumptions, not outcome predictions. Hindsight remembers the person and resume context; it never certifies evidence.

Read README.md, docs/PRD_v12.md, docs/WIKI_SCHEMA.md and docs/EVALUATION_v12.md in the build package. Opening the HTML runs local interface/animation/authoring, not provider inference. Configure the server and validate real audio, identity, memory and decision services before a pilot.
