# Source and asset scope

The ATLAS frontend renderer and interface code in this package are an original implementation for this conversation. No source from the referenced restrictive JARVIS project is copied. The image concept is a design reference, not a screenshot of an operating service.

`assets/Mantu.svg` is the user's supplied brand asset and remains subject to the owner's trademark and brand rules. SHA-256: `92c5ff21779f09199097a2971c172453017f0d2581a0ced6f54fe486ba9b6c2b`. No font files are distributed. Space Grotesk is requested locally with system fallbacks; this does not prove approved typography is installed on a user's device.

NVIDIA PersonaPlex source and model weights are not bundled. Obtain them from their official repository/model card and comply with their separate licenses and access conditions. Python, aiohttp, Microsoft MSAL, Hindsight client, NVIDIA Riva client, FFmpeg, pytest, Playwright and Node.js are third-party runtime/test dependencies governed by their own licenses. No third-party dependency binaries or credentials are bundled.

This file is a source-scope note, not a legal clearance of a corporate deployment.

These providers and the requested Hindsight/Graphify repositories have separate terms and deployment requirements.
