The ATLAS frontend renderer and interface code in this package are an original implementation for this conversation. No source from the referenced restrictive JARVIS project is copied. The image concept is a design reference, not a screenshot of an operating service.

## Natural Earth v5.1.2 (world map data)

The "Project at a glance" location map uses Natural Earth admin-0 country data, tag `v5.1.2` of `nvkelso/natural-earth-vector`. Natural Earth is in the **public domain** (https://www.naturalearthdata.com/about/terms-of-use/). No permission is needed, and the credit "Made with Natural Earth" is optional.

| Input | Pinned URL | SHA-256 | Bytes | Used for |
|---|---|---|---|---|
| `ne_110m_admin_0_countries.geojson` | https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_110m_admin_0_countries.geojson | `6866c877d39cba9c357620878839b336d569f8c662d3cfab4cb1dbe2d39c977f` | 838,726 | country shapes, label points, names |
| `ne_50m_admin_0_countries.geojson` | https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.2/geojson/ne_50m_admin_0_countries.geojson | `3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb` | 3,083,490 | small-territory marker points and names only |

- **Derived asset:** `assets/geo/world-110m.json` (110,856 bytes; about 42.6 KB gzip -9). It is generated by `scripts/build_world_map.py`, which uses only the Python standard library. The script checks both SHA-256 values and refuses to build on a mismatch. The source files are not committed. To regenerate offline, run `python3 scripts/build_world_map.py --src DIR`. To check that the committed asset is byte-identical, add `--check`.
- **Transformations:**
  - Antarctica (ATA) is dropped, and latitude is clipped to -58..84.
  - The map uses Mercator, 1000 units wide by 668 high. Absolute coordinates are rounded to 0.1 before the relative SVG path encoding.
  - It holds 176 country shapes plus 81 small-territory marker points. The markers are the 65 territories missing at 1:110m (for example SGP, HKG, MCO, MLT and BHR) and 110m countries too small to see (for example LUX).
  - Graticule lines run every 10°.
  - A *main box* for each country is taken from its largest polygon, so zooming to France ignores French Guiana.
  - A `provenance` object inside the asset records the URLs, tag, hashes, projection and generator version. It has no timestamp, so the output stays deterministic.
- **Gazetteer:** country names in English, French, German, Spanish, Italian, Dutch and Portuguese come from the Natural Earth name fields. The generator adds original ATLAS lists:
  - curated aliases (UK, USA, Holland, England, native names such as Deutschland and Česko, and others)
  - words that are never matched (for example German *Island* for Iceland, and *Granada*)
  - ambiguous names (Congo, Korea, Saint Martin, New Guinea, Virgin Islands, Timor)
  - false friends (New South Wales, New England, Jersey City, French Guiana)
  - US-state context, so that "Atlanta, Georgia" is not read as the country.
- **Boundary policy:** Natural Earth draws *de facto* boundaries. The map is illustrative, not authoritative, and the UI caption must say so. Point-in-polygon checks against v5.1.2 at 1:110m found the following:
  - Crimea lies inside Russia.
  - The Morocco polygon includes the Moroccan-administered west of Western Sahara, including Laayoune and Dakhla. A separate Western Sahara feature covers the rest.
  - France includes French Guiana, and Norway includes Svalbard.
  - Kosovo, Northern Cyprus, Somaliland, Taiwan and Palestine are separate features.
  - Siachen Glacier appears only as a marker.

  The owner still has to decide whether this is acceptable for customer-facing exports. The alternative is a 1:10m point-of-view pipeline, at about 13 MB of source data per view.
- **Not vendored:** no d3, d3-geo, topojson, topojson-client, world-atlas or visx code or data is included. The map is pre-projected at build time, and `src/geo.js` is original code.

- The placeholder icons `color.png` and `outline.png` are generated by `build_teams_package.py --make-placeholder-icons` (a plain ring). They are original, marked as placeholders inside the PNG, and are not the Mantu logo.
