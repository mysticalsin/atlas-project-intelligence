# Security

Report a vulnerability through [GitHub Security Advisories](https://github.com/mysticalsin/atlas-project-intelligence/security/advisories/new).

Please include what you can do, what you expected, and a synthetic reproduction. Do not include customer stories, private memory, credentials, or a live token. A public issue is the wrong place for those.

This project does not publish a personal phone number or mailbox for security reports. The advisory form is the contact.

Atlas keeps provider credentials on the server. The browser bundle is not a place to put a key, and a local preview does not enable a voice provider. If you find material that looks like a credential in git history, report it through the advisory form. Do not open a pull request that only deletes it: a history rewrite and a rotation are separate decisions.
